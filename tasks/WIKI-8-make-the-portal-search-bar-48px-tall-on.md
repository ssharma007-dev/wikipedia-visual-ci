# WIKI-8 — Make the portal search bar 48px tall on phones for easier tapping

**Type:** Task · **Priority:** Medium · **Status:** In Progress · **Reporter:** Shreya Sharma
**Source:** Jira — https://testing-visual-ci.atlassian.net/browse/WIKI-8
**Labels:** visual

### User story

As a mobile reader, I want a bigger search bar so it is easier to tap.

### Scope

- Portal page, search input and Search button, phone breakpoint (<= 480px) only.

### Acceptance criteria

1. On phone, the search input and the Search button are both 48px tall and aligned.
2. The button stays directly to the right of the input.

### Must not change

- Desktop and tablet: the search bar stays exactly as today.
- Everything else on the portal and on article pages.
