# WIKI-16 — Make the Donate link bold in the article header

**Type:** Task · **Priority:** Medium · **Status:** Done · **Reporter:** Shreya Sharma
**Source:** Jira — https://testing-visual-ci.atlassian.net/browse/WIKI-16
**Labels:** visual

### User story

During the fundraising campaign, the Donate link should stand out a little more, using the existing brand styles.

### Scope

- Article pages, header link "Donate".

### Acceptance criteria

1. The header "Donate" link text is bold (font-weight 700) on desktop and phone.
2. Its color stays the same (design system: Header links).

### Must not change

- The color of the Donate link.
- Every other header link ("Join Wikipedia", "Log in").
- The portal page.
