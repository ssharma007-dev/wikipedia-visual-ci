# WIKI-104 — Highlight the Donate link for the fundraising campaign

**Type:** Visual change · **Priority:** High · **Reporter:** Fundraising / Marketing

## User story

During the year-end fundraising campaign, the "Donate" link in the article header should stand
out so more readers notice it.

## Scope

- **Article pages**, header link "Donate".

## Acceptance criteria

1. The header "Donate" link text is **red (`#D73333`)** on desktop and phone.
2. Its position and size do not change.

## Must not change

- Every other header link ("Create account", "Log in") and the rest of the page.
- The portal page.
